# 📊 N100 Financial Intelligence Platform

An end-to-end Financial Intelligence Platform that performs ETL, financial ratio computation, stock screening, peer comparison, valuation analysis, predictive analytics, and interactive visualization for Nifty 100 companies.

The platform automates the complete financial analysis workflow—from ingesting raw financial statements to generating actionable insights through dashboards, reports, and machine learning models.

---

# 🚀 Project Overview

The N100 Financial Intelligence Platform is designed to analyze publicly available financial data of Nifty 100 companies and transform it into meaningful business insights.

The project includes:

- Automated ETL pipeline
- Data Quality Validation
- SQLite Data Warehouse
- Financial Ratio Engine
- Stock Screener
- Peer Comparison Engine
- Interactive Streamlit Dashboard
- Valuation Engine
- Cash Flow Intelligence
- NLP-based Pros & Cons Generator
- Company Tearsheet Generator
- Machine Learning based Company Clustering
- Predictive Analytics

---

# ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/N100_FINANCIAL_INTELLIGENCE_PLATFORM.git
```

Move into the project directory:

```bash
cd N100_FINANCIAL_INTELLIGENCE_PLATFORM
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Dashboard

```bash
streamlit run dashboard/app.py
```

The application will be available at:

```
http://localhost:8501
```
